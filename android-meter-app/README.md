# Мои счётчики

Первый тестовый Android-проект для учёта бытовых счётчиков.

## MVP
- несколько адресов;
- несколько счётчиков на каждом адресе;
- произвольное название и единица измерения;
- ручной ввод показаний;
- фотография счётчика через системную камеру;
- локальное хранение данных;
- история показаний;
- расчёт расхода между двумя последними показаниями;
- защита от случайного ввода показания меньше предыдущего.

## Технологии
- Kotlin;
- Jetpack Compose;
- Android Gradle Plugin 9.3.0;
- Compose BOM 2026.08.00;
- compileSdk / targetSdk 37;
- minSdk 26.

## Сборка
Проект не содержит Gradle Wrapper в первой ревизии. Перед сборкой сгенерируйте Wrapper Gradle 9.5.0, затем выполните:

```bash
./gradlew :app:assembleDebug
```

Ожидаемый APK после успешной сборки:

`app/build/outputs/apk/debug/app-debug.apk`
