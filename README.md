# Xteink Daily News

Техновости для **Xteink X3** (CrossPoint). Один EPUB в день.

## OPDS

```
https://raw.githubusercontent.com/egor0997777-byte/xteink-daily-news/main/opds.xml
```

Файл: `YYYY-MM-DD.epub`

### Как читать на X3
- Оглавление: **источник → статья**
- Полный текст статьи (где RSS даёт только анонс — подгружается со страницы)
- Без картинок

### Лайфхакер
В списке есть. RSS `lifehacker.ru/feed/` с облачных IP часто отдаёт пустой ответ (защита сайта). Если лента снова заработает — появится в книге автоматически.

Обновление ~07:00 МСК.
