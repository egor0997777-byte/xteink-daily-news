# Xteink Daily News

Техновости для **Xteink X3** (CrossPoint). Один EPUB в день.

## OPDS

```
https://raw.githubusercontent.com/egor0997777-byte/xteink-daily-news/main/opds.xml
```

Файл: `YYYY-MM-DD.epub` (и `latest.epub`).

Внутри EPUB главы = источники (Хабр, Лайфхакер, VC…). Только текст.
