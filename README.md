# Xteink Daily News

Утренний тех-выпуск для **Xteink X3** (CrossPoint).

## OPDS

```
https://raw.githubusercontent.com/egor0997777-byte/xteink-daily-news/main/opds.xml
```

Файл: `YYYY-MM-DD.epub` (~50–70 материалов).

### Структура EPUB
1. Обложка (дата, счётчики)
2. **Главное** — 5–8 материалов (ссылки на полный текст без дублей)
3. ИИ · Гаджеты · ИТ · Разработка · Наука · Остальное

У каждой статьи: заголовок, `Источник · дата · время`, лид, полный текст. Без картинок.

### Источники
Хабр, Лайфхакер, VC.ru, iXBT, 3DNews, Tproger, DTF, Computerra, N+1, HighTech, Xakep, CNews, Mobile-Review.

Обновление ~07:00 МСК.
