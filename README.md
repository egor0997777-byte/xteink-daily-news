# Xteink Daily News

Утренний тех-выпуск для **Xteink X3** (CrossPoint / OPDS).

## OPDS

```
https://raw.githubusercontent.com/egor0997777-byte/xteink-daily-news/main/opds.xml
```

Файл: `YYYY-MM-DD.epub` + `latest.epub` (~50–65 материалов).

### Структура EPUB
1. **Обложка** — дата, счётчики по разделам, время сборки
2. **Главное** — 5–8 материалов (только лид + ссылка на полный текст, без дублей)
3. ИИ · Гаджеты и устройства · ИТ / администрирование · Разработка · Наука · Остальное

У каждой статьи:
- заголовок
- `Источник · дата · время`
- короткий лид (1–3 предложения)
- полный текст (очищенный)
- ссылка на оригинал

Без картинок, без JS, минимум CSS — быстро открывается на e-ink.

### Источники
Хабр (несколько лент, общий лимит ≤18), Лайфхакер, VC.ru, iXBT, 3DNews, Tproger, DTF, Computerra, N+1, HighTech, Xakep, CNews, Mobile-Review.

### Рейтинг «Главное»
Простая прозрачная формула (без ИИ):
- длинный полный текст → +1.5…3
- тема (ИИ/наука выше) → +1…2.5
- свежесть (<12 ч / <24 ч) → +1…2
- длина заголовка 30–120 символов → +0.5

### Обновление
~07:00 МСК (cron 04:00 UTC) + ручной `workflow_dispatch`.

Только stdlib Python 3.
