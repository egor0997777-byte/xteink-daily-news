# Xteink Daily News

Утренний тех-выпуск для **Xteink X3** (CrossPoint).

## OPDS

```
https://raw.githubusercontent.com/egor0997777-byte/xteink-daily-news/main/opds.xml
```

Файл: `YYYY-MM-DD.epub` (~50–70 материалов).

### Структура EPUB
1. Обложка (дата, счётчики)
2. **Главное** — ссылки без дублей текста
3. ИИ · Гаджеты · ИТ · Разработка · Наука · Остальное

У статьи: заголовок, `Источник · дата · время`, лид, полный текст. Без картинок.

Обновление ~07:00 МСК.
